# 劇情閱讀器改善與驗收紀錄（2026-09-16）

分支：`codex/story-reader-improvements`。基於播放穩定性修復分支的 `ee6ee6c0`，在原工作目錄修改，沒有建立工作區副本或複製音訊。

## 已完成

1. 資料庫只從網站本身取得；發布版本 `hash_<12位>` 以 SHA-256 驗證。新版下載與驗證完成前保留舊快取，資料與版本在同一筆 IndexedDB 記錄中提交。
2. 快取不可用時仍允許當次閱讀，顯示提醒。角色篩選與閱讀進度也能容忍本機儲存被禁止。SQL 引擎與下載均有逾時限制。
3. Space 播放／暫停、Esc 停止 AUTO；避開輸入框、原生按鈕、輸入法組字、修飾鍵與彈窗。上一話、下一話、回到頂端改用原生按鈕。
4. 手機官方大綱預設收合，展開才請求；舊話數延遲回傳仍會被忽略。
5. 保存最後閱讀話數與對白位置；「繼續閱讀」可從首頁回到該位置。僅保存在該瀏覽器，不會同步帳號。
6. 「分享本話」產生 `#story=<id>&line=<index>` 連結；支援重新整理、瀏覽器返回及跨劇情分類跳轉。剪貼簿不可用時顯示可選取的連結欄位。
7. 修正手機閱讀區被水平快速目錄撐寬的問題。新話數載入失敗時清空舊播放清單，避免播放上一話。
8. 打包器已納入 `reader-navigation.js` 與內容雜湊版本，驗證器也檢查新檔案。

- Python：`tests.test_bundle_slimming` 與 `tests.test_story_data_service` 共 55 項通過；測試資料建立於系統暫存目錄。

## 已知既有問題

`tests/test_reality_avatars.js` 仍會在 `dist_story_map/icon/unit/100132.webp` 缺檔處失敗。這是審查前就存在的發布產物問題；本次未重建或修改發布目錄，也未弱化該測試。摘要介面與劇情服務測試的過時文字斷言、缺失的 DOM／播放替身則已更新。

開發資料的日期型 `db_version` 僅能核對來源與大小；正式打包產生的雜湊版本才會進行內容雜湊驗證。新版本下載失敗會保留原快取但要求重試，不會把舊資料冒充新版。

## 手動驗收

在本機 HTTP 伺服器開啟 `dashboard/story_map.html`（正式發布入口由打包器產生）：

1. 開任一劇情，捲動數段後離開閱讀器；重新整理並點「繼續閱讀」，應回到同一話附近位置。
2. 點「分享本話」，貼到新分頁，應直接開啟同一話。切下一話後按瀏覽器返回，應回前一話。
3. 游標離開輸入欄與按鈕後，Space 應切換 AUTO，Esc 應停止；輸入框內按空白鍵應正常輸入。
4. 手機寬度下，官方大綱預設收合，點開才顯示；頁面不應橫向溢出。
5. 若瀏覽器禁止快取，應看到提醒，但仍可讀取對白。
